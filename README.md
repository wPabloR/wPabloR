## 📌 Proyectos Destacados

### 🎲 BetMate - Plataforma de Apuestas entre Amigos
Aplicación web full-stack para gestionar apuestas informales con:
- **Frontend**: React con Hooks y Context API
- **Backend**: Python con Flask y REST APIs
- **ORM**: SQLAlchemy para gestión de base de datos
- **Autenticación**: JWT y gestión de sesiones
- **Features**: Sistema de notificaciones, historial de apuestas, ranking de usuarios
