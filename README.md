## 📌 Proyectos Destacados

### 🏨 Nite - Plataforma Hotelera Multi-tenant
Plataforma hotelera full stack con asistente conversacional de IA:
- **Frontend**: React y Next.js, con chat en streaming, mapas y panel de usuario
- **Backend**: APIs REST con Node.js y Express, arquitectura por capas (casos de uso, DAOs, infraestructura)
- **Base de datos**: PostgreSQL / Supabase
- **IA**: RAG y pgvector para indexación documental y respuestas contextualizadas
- **Integraciones**: PMS Suite (TCP/XML), onboarding por NFC, WhatsApp
- **Features**: Autenticación y autorización multirol, internacionalización ES/EN

### 🎲 BetMate - Plataforma de Apuestas entre Amigos
Aplicación web full-stack para gestionar apuestas cerradas entre un grupo privado:
- **Backend**: Diseño y desarrollo completo con persistencia de datos mediante SQL
- **Frontend**: Salas de juego, invitaciones y chat entre jugadores
- **Autenticación**: Autorización multirol
